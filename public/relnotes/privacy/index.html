GitHub App

The relnotes GitHub App is read-only. Its permissions are Pull requests: read, and Metadata: read. It never reads your code, and it never stores your code.

What relnotes stores

  • The GitHub installation ID
  • Repository names
  • For each merged pull request: the number, title, description, and link
  • The generated release-note entries
  • The Stripe customer ID, the Stripe subscription ID, and the plan status

Whether relnotes stores the customer email is unknown: [CUSTOMER EMAIL STORAGE].

Anthropic

relnotes sends pull request titles and descriptions to the Anthropic API so they can be summarized. That processing is covered by Anthropic's own terms:

  • Anthropic Commercial Terms of Service
  • Anthropic Privacy Policy

Payments

Stripe handles all payment and card data. relnotes never sees your card. relnotes keeps the Stripe customer ID, the Stripe subscription ID, and the plan status. Stripe's privacy policy applies to the payment.

How long data is kept

  • Release-note entries are deleted after [RETENTION DAYS].
  • All relnotes data is purged when the subscription is cancelled.
  • When a repository is removed from the App, that repository's data is purged.
