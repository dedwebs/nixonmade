What's inside

  • A GitHub App. You choose which repositories it can see.
  • One line per merged pull request, written for users, not developers.
  • Internal-only changes are left out automatically.
  • One private changelog URL for your account, served as Markdown you can paste or fetch.
  • Read-only: it reads pull requests and never writes to your code.
  • Planned pricing: $19 a month per repository (covers up to 300 merged pull requests a month each), or $49 a month for a team with unlimited repositories (up to 1,000 merged pull requests a month). Pull requests opened by bots, like dependency updates, are skipped and never count.

Who it's for

Small dev teams, indie hackers, and open-source maintainers who merge often and would rather not write the changelog by hand.

What you get

The changelog is plain Markdown, newest first. Example entries below, written by hand in the same format.

# Changelog

- Plan changes in Stripe now take effect right away, including upgrades and failed payments. — acme/billing
- Exports now include a summary row with totals for each column. — acme/reports
- Fixed a sign-in loop that could trap Safari users on the login page. — acme/web

FAQ

Can I buy it today?
No. Join the waitlist at hello@nixonmade.com.
Does it touch my code?
No. It only has read access to pull requests and repository metadata.
Which model writes the notes?
Claude, from Anthropic. It sees the pull request title, description, and a size-capped diff. Pull request text is treated as data, never as instructions, and links, images, and HTML are stripped from every line before it is stored.
What happens if I cancel?
Stored notes are deleted. Cancellation stops the next charge. See our refund policy, the terms, and the privacy page.
Private repositories?
Yes, for any repository you grant the app.
