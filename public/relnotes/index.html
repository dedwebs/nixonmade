FAQ

Does it touch my code?
No. It only has read access to pull requests and repo metadata.
Which AI does it use?
It uses a commercial LLM API to summarize PR titles and descriptions.
What happens if I cancel?
Your stored notes are purged. Cancellation stops the next charge, and the current month is not refunded. See the refund policy, the terms, and the privacy page.
Private repos?
Yes, for any repo you grant the App.
