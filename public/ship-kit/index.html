FAQ

Which apps does it cover?
SwiftUI iOS apps, including apps with extensions.
Do I need a Mac?
Yes. Xcode builds and uploads run on your Mac.
Which agents does it include skills for?
Cursor and Claude Code. The runbook is for an agent that can run shell commands.
Does the kit submit my app to App Store review?
No. App Store submission is outside this kit. The export script and the TestFlight upload script are included files.
Where do API keys go?
The scripts read keys from your own environment. The kit does not send those keys to NixonMade.
What do updates cover?
Updates cover 1.0.x. A later major version is not included. See the terms.
