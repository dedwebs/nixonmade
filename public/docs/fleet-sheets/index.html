Fleet Sheets

Fleet Sheets

A macOS disk image. It turns a device export into an Excel workbook with a summary, tables, charts, and pivot tables. Import only: no API access and no credentials. One organization per license. The workbook needs Microsoft Excel.

Fleet Sheets product page

Field Kit Ship Kit Fleet Sheets

What's in it

  • A macOS disk image (.dmg)
  • The jxr universal2 binary
  • A Python wheel
  • README, QUICKSTART, CHANGELOG, and LICENSE
  • Third-party notices
  • Sample exports and a sample workbook (example data)

The sample workbook is example data, not a real fleet. Its sheets include a summary, pivot tables, and a computers-by-OS chart.

Requirements

  • A Mac, because the download is a .dmg
  • Microsoft Excel, to open the workbook
  • A device export you already have. Fleet Sheets does not connect to the MDM.

Sources

  • Jamf Pro: CSV or .xlsx
  • Kandji: Device Views CSV export
  • Microsoft Intune: the device list export from the portal, or the Graph Devices report
  • Addigy: the devices table export
  • Any other CSV, by mapping the columns

What it reads

  • Mosyle is not supported yet.
  • Kandji FileVault status is not in the Device Views export, so that figure is skipped for Kandji.
  • Other Kandji Prism or category exports are not supported. Other Intune reports are not supported.
  • The download is a macOS disk image. The workbook needs Microsoft Excel.

Install and getting started

  1. Buy Fleet Sheets on the product page. Checkout is on Stripe.
  2. After payment, Stripe opens your download page. Bookmark that page. The button lasts 15 minutes, and you can download five times. That page is how you download again. If you saved the checkout session id, enter it on the re-download page.
  3. Open the .dmg on your Mac.
  4. Read QUICKSTART and README inside the disk image.
  5. Open the sample workbook if you want to see the example summary, pivots, and chart before you use your own export.

Walkthrough

  1. Open the disk image and read QUICKSTART.
  2. Look at the sample workbook. The summary sheet lists example KPIs. The pivot sheet has computers by OS and model, FileVault status, mobile devices, and patch status. The computers-by-OS sheet has a table and a bar chart. Those numbers are example data.
  3. Import your own device export: Jamf Pro, Kandji Device Views, an Intune device list or Graph Devices report, an Addigy devices table, or another CSV with the columns mapped.

Configuration

A license covers one organization. There is no MSP or multi-client tier. A second organization needs its own purchase.

FAQ

Does it connect to the MDM?
No. It reads a file you already exported. It does not use an API and does not need credentials.
What does one purchase cover?
One organization. One license. No multi-client tier.
What does it cost?
$29 for one organization.
Is the sample workbook my fleet?
No. It is example data shipped with the kit.
