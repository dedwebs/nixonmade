Fleet Sheets

Fleet Sheets

A Mac app that turns a device export into an Excel report with a summary, tables, charts, and pivot tables. You drag in a file you already exported. No API access and no credentials. One organization per license. The report needs Microsoft Excel.

Fleet Sheets product page

Field Kit Ship Kit Fleet Sheets

What's in it

  • A disk image (.dmg) with the Fleet Sheets app
  • Sample exports you can try from inside the app (example data, not a real fleet)
  • Built-in help that shows how to make each export

Requirements

  • macOS 13 or later, on an Intel or Apple silicon Mac
  • Microsoft Excel, to open the report
  • A device export you already have. Fleet Sheets does not connect to the MDM.

Exports it reads

  • Jamf Pro: CSV or .xlsx
  • Kandji: Device Views CSV export
  • Microsoft Intune: the device list export from the portal, or the Graph Devices report
  • Addigy: the devices table export
  • Any other CSV or .xlsx, by matching the columns in the app

Fleet Sheets detects Jamf Pro, Kandji, Intune, and Addigy exports on its own.

Limitations

  • Microsoft Excel is required to open the report.
  • Needs macOS 13 or later.
  • Mosyle is not supported yet.
  • Kandji FileVault status is not in the Device Views export, so that figure is skipped for Kandji.
  • Other Kandji Prism or category exports are not supported. Other Intune reports are not supported.

Install

  1. Download Fleet Sheets from the download page Stripe opens after payment. Bookmark that page. The button lasts 15 minutes, and you can download five times. If you saved the checkout session id, enter it on the re-download page.
  2. Open the downloaded .dmg file.
  3. In the window that opens, drag Fleet Sheets into the Applications folder.
  4. Open Fleet Sheets from Applications. The first time, macOS asks whether you want to open an app downloaded from the internet. Click Open.

Make a report

  1. Export your devices from your device management tool as a CSV or Excel file. In the app, "How do I export my devices?" shows how for each tool.
  2. Drop the file onto the Fleet Sheets window, or click Choose File.
  3. Fleet Sheets shows what it found, such as "Jamf export · 70 devices", and notes anything the export is missing.
  4. If it doesn't recognize the file, it asks which columns are which. Pick the columns for computer name and serial number. macOS version and model are optional. Then click Continue.
  5. Click Create Report and choose where to save it.
  6. Click Open in Excel, or Show in Finder.

No export handy? Use "Try a sample" on the first screen. Samples are example data, not a real fleet.

Configuration

A license covers one organization. There is no MSP or multi-client tier. A second organization needs its own purchase.

FAQ

Does it connect to the MDM?
No. It reads a file you already exported. It does not use an API and does not need credentials.
What does one purchase cover?
One organization. One license. No multi-client tier.
What does it cost?
$29 for one organization.
Do I need to use Terminal?
No. Fleet Sheets is a regular Mac app.
Are the samples my fleet?
No. They are example data included with the app.

Troubleshooting

If Fleet Sheets can't read your export, it says why and what to try. If that doesn't help, email hello@nixonmade.com with the name of your device management tool and the message you saw.
