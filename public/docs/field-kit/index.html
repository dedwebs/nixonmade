What's in it

  • 3 PPPC profile templates, with a README
  • 5 extension attribute scripts: FileVault, firewall, Gatekeeper/SIP, last reboot, and local admins
  • 2 guides: a createinstallmedia EPERM runbook, and PIV smart-card troubleshooting
  • README, CHANGELOG, and LICENSE

The FileVault script in the kit is read-only. It runs as root during a Jamf inventory update and returns On, Off, Encrypting, Decrypting, or Unknown.

Requirements

  • Jamf Pro, so you can upload a configuration profile and add extension attributes
  • A Mac you can test on before you roll a profile out

Install and getting started

  1. Open the README that comes in the download.
  2. In each PPPC template, replace the example bundle identifier, the example Team ID, and the code requirement before you use it. The full disk access template in the kit says to take the code requirement from codesign -dr on the app.
  3. The template comment says to generate new UUIDs so profiles never collide.

Walkthrough

Upload a PPPC profile

  1. Finish the placeholder replacements and new UUIDs above.
  2. Upload the profile unsigned in Jamf Pro under Configuration Profiles, Upload.
  3. Test on one Mac first, as the template comment says.

Add the extension attributes

The kit has five scripts: FileVault, firewall, Gatekeeper/SIP, last reboot, and local admins. The FileVault script is a shell script that prints a Jamf result string.

Use the guides

The createinstallmedia EPERM runbook is for the failure that happens when that command is launched from an app. The PIV guide is the smart-card troubleshooting document in the kit.

Configuration

Before upload, the full disk access template still contains com.example.app, TEAMID1234, and a code requirement placeholder. Replace those. Generate new payload UUIDs for your organization.

Troubleshooting

If createinstallmedia fails with "Operation not permitted" when an app launches it, use the EPERM runbook in the kit. The runbook records that the same installer and the same USB drive worked when the command was run manually from Terminal, with Terminal granted Full Disk Access.

If the FileVault script prints Unknown, the status string did not match On, Off, Encrypting, or Decrypting.
