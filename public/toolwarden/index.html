Toolwarden · Desktop app and CLI · Works with Jamf Pro

The daily Jamf Pro jobs, in one careful window.

Toolwarden is a desktop app and command-line tool for Mac admins who manage Macs with Jamf Pro. Look up a Mac, flush stuck MDM commands, check how a policy is landing across a group, build privacy profiles, and inspect packages without opening five browser tabs.

For MSPs and small Mac IT teams.

Free and open source (MIT). Needs macOS 11 or later.

Nothing changes until you say so

Reading is free. Writing is not. Toolwarden never changes anything in Jamf Pro until you click a green button and confirm.

  • Every write is a green button, followed by a confirm.
  • Riskier actions ask for more. Flushing pending and failed commands means typing the computer name.
  • Privacy profiles upload unscoped, so nothing reaches a Mac until you scope it in Jamf Pro.
  • AI only fills in forms. It never saves, uploads, or sends a command. You review and click.

What it does

  • Devices

    Look up a Mac by serial number or name. See last check-in, inventory, and failed or pending MDM commands. Flush failed commands after you confirm.

  • Deployments

    Pick a group and a policy to see which Macs completed, failed, or have not run it yet. Or open one Mac's policy logs.

  • Packages

    Build installer packages with the Inlet packaging window, then hand a package already in Jamf Pro to a policy.

  • Policies

    Create or update a policy with a custom trigger, a package, and a static group scope. Preview the XML before you save.

  • Groups

    Preview a CSV against a static group, apply the additions, and undo the last apply. Smart groups are left alone.

  • Inspect

    Open a local .pkg to see its payload, scripts, and nested packages. Check its signature, sign a copy, or write an unsigned copy to repack.

  • Privacy

    Build PPPC profiles for Full Disk Access, Accessibility, Automation, and more. Drop in an app, edit an existing profile, export a signed .mobileconfig, or upload it.

  • Practice mode

    A built-in mock Jamf Pro server runs on your Mac with sample packages, groups, and devices. Try every button before you point it at production.

Install

  1. Download the latest Toolwarden .pkg from GitHub Releases.
  2. Open it and follow the installer. The app goes to /Applications/Toolwarden.app.
  3. Open Toolwarden and choose Practice in Settings to try it against the mock server first.
  4. When you are ready, add a Jamf Pro API client in Settings and click Test connection.

From a source checkout, the same tools run in Terminal for scripts and quick checks:

python3 main.py test-jamf
python3 main.py mock-jamf
python3 main.py inspect-pkg /path/to/App.pkg

Who it's for

MSPs and small Mac IT teams who live in Jamf Pro and want the common jobs to be quick and hard to get wrong. It is not a replacement for the Jamf Pro console, and it is not a remote screen-sharing tool.

FAQ

What does it cost?
Nothing. Toolwarden is open source under the MIT license.
Can it change things in Jamf Pro by accident?
Every change needs a green button and a confirm. AI suggestions only fill in the form in front of you.
Can I try it without a Jamf Pro server?
Yes. Practice mode runs a mock server on your Mac with sample data.
It used to be called something else?
Yes. Versions before 0.2.0 were named Jamf Toolbox. Upgrading keeps your settings.
