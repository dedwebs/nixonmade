How these get made

I'm Joe Nixon, a Jamf admin and iOS developer. I run a small team of AI coding agents in Claude Code (engineers, QA, security, and release) and I decide what gets built and what ships. Here's the process every tool goes through.

  1. 01

    It starts as a real chore

    Every tool begins as a job I kept doing by hand in Jamf Pro or a spreadsheet. If I don't need it at work, it doesn't get built.

  2. 02

    Every change is checked

    Each change is its own pull request. It has to build, pass the tests, and clear a QA and security review before it merges.

  3. 03

    Safe to try

    Tools read before they write and ask before they change anything. Toolwarden has a practice mode with fake data, so you can try every button safely.
