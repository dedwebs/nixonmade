# Morning launch checklist

You have a job. This catalog is the 100% AI-product proof. Do not buy your own listing.

## 1. Approve art (you)

1. Run `npm run approve`, then open http://127.0.0.1:8765/approve.html in Chrome or Safari (not the Cursor file preview).
2. Mark each id `approve` or `reject`. If it is almost right, reject — we regenerate, we do not retouch.
3. A set of 3 only lists if **all three** are approved. Orphans become extras or a mixed “gallery” set later.

Reject immediately: logos, movie witches, garbled type, photoreal faces, cute-kawaii slop, anything that looks like a trademark.

## 2. Etsy (first dollar)

1. Create or open the Etsy shop (Nixon Made).
2. Digital download listing. Price **$9** per set of 3 printables.
3. Production: Designed by you / I did / finished product / made to order.
4. Paste from `listings/PASTE.md`. Disclosure sentence stays at the top.
5. Upload the zip from `python3 scripts/export-print-sizes.py --set <slug>` after you approve.
6. Do not run ads on the first listing. Organic sale is the cleanest proof. Log: prompt, file, listing URL, order ID.

## 3. Site

`/halloween/` is a waitlist until an Etsy URL exists. Then replace the mailto with the shop link. Deploy: `npm run deploy`.

## 4. After first sale

Park the profit minus ~25% tax in a separate house-savings account. W-2 still qualifies the mortgage.

## Blocked without you

Etsy account, tax identity, payouts, and the yes/no on each poster. Everything else in this folder is ready to paste.
