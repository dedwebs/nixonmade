# Halloween gothic-romance catalog (2026)

Proof experiment: AI generates the art. You only approve or reject. Stranger purchase = proof.

**Niche:** vintage gothic-romance Halloween. 1920s lithograph / stained-glass / botanical-plate look. Cream paper, ink black, oxblood, muted gold. No logos, no movie witches, no readable poster type (AI type comes out wrong).

**Products after approve:** printable wall-art **set of 3** (multiple sizes in one listing) + matching **PNG sticker sheet**. Same file can go on a tee later. Do not list rejects.

**Etsy disclosure (required):** “This artwork was generated with AI tools from original prompts by Nixon Made. Designed by the seller.” Attribution: Designed by seller.

## Your job

Open `candidates/` images. Mark each id in `queue.md`:

- `approve` — print-clean, on-niche, no IP
- `reject` — garbled, slop, character/logo, too cute, too photo, unreadable

Do not crop, retouch, or add type. If it is almost good, reject and we regenerate.

## Do not print

Disney, Nightmare Before Christmas, Hocus Pocus, Harry Potter, Wednesday, Sonic, Pokemon, sports teams, real brand names, celebrity faces.
